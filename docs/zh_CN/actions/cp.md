# `cp`

将文件或目录复制到目标位置

## 示例

```jsonnet
{ use: 'cp', src: BDIR + '/kernel.config', dest: '.config' }
```

## 字段

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| `src` | `string` | 是 | 源路径，可使用绝对路径；相对路径相对于当前 target 工作目录 |
| `dest` | `string` | 是 | 目标路径，可使用绝对路径；相对路径相对于当前 target 工作目录 |

## 规则

- `src` 是目录时执行目录复制，并允许合并到已存在目录
- `src` 是文件时执行单文件复制，并保留文件元数据
